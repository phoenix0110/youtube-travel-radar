# B 站适配度评分规则（旅游赛道）

## 一、五维软指标（LLM 打分，0-10 分）

| 维度 | key | 定义 | 打分锚点 |
|------|-----|------|----------|
| 视觉冲击 | `visual` | 风景/奇观/画面质感，能否让人"哇"出来 | 10=航拍+4K+绝美自然奇观/极端环境；6=普通城市实拍有构图；3=手持晃动无剪辑；1=纯坐聊 |
| 猎奇新鲜 | `novelty` | 中国观众没见过、超出常识的程度 | 10=极罕见目的地（朝鲜/南极/部落/禁区）；7=小众但有认知（巴尔干/中亚/非洲）；4=热门旅游国（日泰欧美）；1=国内也常见 |
| 文化接近 | `cultural` | 与中国观众的文化/审美共鸣 | 10=中日韩/华人社区/中国元素；7=东南亚/南亚（亚洲熟悉）；4=拉美/中东/非洲；2=纯欧美小镇日常 |
| 叙事适配 | `narrative` | 画面驱动 vs 口播驱动，二创改造难度 | 10=画面自解释、弱口播（航拍/延时/街拍）；7=口播但故事线强（探险叙事）；4=依赖英语段子/当地语言；1=纯对谈/播客 |
| 爆点强度 | `explosion` | 标题党潜力：冲突/反差/悬念/争议 | 10=天然爆点（最危险/最穷/被骗/禁区/极端体验）；5=风景好但平稳；1=平淡流水账 |

## 二、总评公式

```
total = 0.25*visual + 0.20*novelty + 0.15*cultural + 0.10*narrative + 0.30*explosion
```

硬分微调：
- **时长适配**：8–25 分钟最适配 B 站（+0.2）；<4 分钟偏短（0）；>40 分钟偏长（-0.1）

## 三、人群映射（每视频标 1–2 个主适配人群）

| 人群 | 画像 | 选题偏好 | 时长 | 内容形态 |
|------|------|----------|------|----------|
| **B. 背包客/学生** | 18–28，穷游/间隔年 | 省钱攻略/搭车/青旅/签证 | ≤20min | 实用+代入感强 |
| **E. 城市探索** | 22–35，都市人群 | 城市Vlog/美食/建筑/夜景 | ≤15min | 节奏快、画面精致 |
| **A. 户外冒险** | 20–35，运动型 | 登山/徒步/潜水/极限 | 10–30min | 肾上腺素、第一视角 |
| **L. 奢华精致** | 28–45，消费力强 | 度假酒店/头等舱/米其林 | 不限 | 生活方式向、精致感 |
| **K. 知识/文化** | 25–40，泛知识消费 | 历史遗迹/地理科普/人文纪录 | 15–40min | 叙事强、有深度 |

**类型 → 人群速查**：
- 环球旅行(1) → K / B
- 城市探索(2) → E / L
- 户外冒险(3) → A / B
- 文化体验(4) → K / E
- 穷游背包(5) → B / A
- 奢华度假(6) → L / E

## 四、打分输出格式（scores.json）

```json
[
  {
    "video_id": "xxxx",
    "visual": 9, "novelty": 8, "cultural": 7, "narrative": 8, "explosion": 9,
    "audiences": ["B", "K"],
    "reason": "一句话：这个选题的爆点是什么，为什么 B 站用户会点",
    "bili_title_hint": "如果二创，标题可以往哪个方向打"
  }
]
```

打分依据：标题 + 频道背景 + 简介。信息不足时保守打 5 分，不臆造。
